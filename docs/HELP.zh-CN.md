# 离线使用帮助

## 1. 导入文件

选择 XYYYYY（共用一列电位）或 XYXYXY（每个扫速对应一对电位/电流列），再选择 CSV、TXT 或 XLSX 文件。正确设置首行为表头还是数值数据。XLSX 使用首个可用工作表。保留完整 CV 的原始扫描顺序和回扫分支，不要按电位排序。最多支持 20 组扫速。

## 2. 单位与扫速

电位使用 V，扫速按 mV/s 输入，顺序必须与电流列一一对应。文件中电流统一使用 A，不要混用 A 和 mA。表头可辅助推断扫速，但分析前仍需核对。TXT 支持制表符、逗号、分号或一致空白分隔。

## 3. 运行分析

建议先使用自动电位间隔和自动转折点修剪，检查预览与扫速后点击运行分析。调整数据格式或首行设置时会重新解析已选文件。关闭前请导出结果；软件不会自动保存原始数据或分析会话。

## 4. b 值与峰点调整

回归公式为 log(|i|) = log(a) + b log(v)。R² 阈值与近零电流稳定性是独立的质量判据。在峰值模式中，添加峰时可选择扫描分支，并对各扫速的对应实测点定位、确认。不要在缺乏数据支持的位置强行指定峰；需要检查低质量或缺失点。

## 5. Dunn 重构

传统局部拟合为 i(V) = k1(V) v + k2(V) sqrt(v)。随后通过置信度感知正则化估计一个共享 g(V)，满足 0 ≤ g(V) ≤ 1，且 i_cap,f/r(V) = g(V) i_raw,f/r(V)。阈值模式默认 R² = 0.95，用于可信锚点置信度；加权模式使用连续 R² 置信度，不改变 b 值的质量筛选。正则化重构并不等同于未经约束的逐点 Dunn 拟合。

## 6. 解释与导出

同时检查拟合质量、正反扫分支和原始 CV。正则化电容贡献依赖模型，并非对某种机制的唯一实测量。可导出 CSV 表格、SVG/PNG 图片，或勾选表头复选框复制列。报告贡献率时使用当前图及其对应导出数据，并记录版本、单位、R² 模式/阈值、电位间隔和转折点修剪设置。

## 7. 常见问题

导入失败时检查布局、数值列数、首行设置和小数分隔符。可将第一张工作表另存为标准 .xlsx 或 UTF-8 CSV。各扫速应有兼容的扫描分支/方向以及共同电位范围。应根据可见错误排查，不能仅通过放宽阈值隐藏问题。

## 8. 离线使用与更新

软件自带运行环境，文件仅在本机处理，无云端计算或遥测。帮助和更新记录离线可用。手动更新时替换软件，原始文件与导出结果请单独备份。未签名软件可能触发系统安全提醒，请仅使用可信来源的软件包。
